mFkGames Sıfır Günlük (Zero-Logs) & Şifreleme İlkeleri

1. Sıfır Günlük (Zero-Logs) Taahhüdü

mFkVpN altyapısı hiçbir kullanıcı etkinliğini, ziyaret edilen web sitelerini, DNS sorgularını, IP adreslerini veya iletilen veri içeriklerini diske kaydetmez. Bağlantılar doğrudan RAM üzerinden işlenir ve oturum sonlandığında bellek temizlenir.

2. Uçtan Uca Asimetrik Kriptografi (X25519)

Cihaz yetkilendirmesi sırasında kullanılan WireGuard özel anahtarları (Private Key) tamamen istemci tarafında (tarayıcınızda) yerel olarak oluşturulur. Özel anahtarınız asla sunucuya, üçüncü taraflara veya ağ ortamına gönderilmez.

3. Çerez ve İzleme Engelleme

Panelimizde üçüncü taraf analiz araçları (Google Analytics, reklam izleyicileri vb.) bulunmaz. Tercihler yalnızca yerel tarayıcınızda (Local / Session Storage) saklanır.

4. Güvenli API ve Şifrelenmiş İletişim

Sunucu yönetim çağrıları GitHub REST API v3 ve SSH tüneli üzerinden 256-bit TLS şifreleme ve dinamik oturum belirteçleri ile korunmaktadır.

5. Telif & Mülkiyet
