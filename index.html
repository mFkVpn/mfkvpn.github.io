mFkGames Sıfır Günlük (Zero-Logs) İlkeleri

1. Sıfır Günlük (Zero-Logs) Taahhüdü

mFkVpN altyapısı hiçbir kullanıcı etkinliğini, ziyaret edilen web sitelerini, DNS sorgularını, IP adreslerini veya iletilen veri içeriklerini kaydetmez. Bağlantılar doğrudan RAM üzerinden işlenir.

2. Uçtan Uca Kriptografi (X25519)

Cihaz yetkilendirmesi sırasında kullanılan WireGuard özel anahtarları yerel olarak tarayıcınızda üretilir ve asla sunucuya gönderilmez.

3. Çerez ve İzleme Engelleme

Panelimizde üçüncü taraf analiz veya reklam takip kodu bulunmaz. Tüm ayarlar yerel depolamanızda saklanır.

4. Güvenli Yönetim Tüneli

Sunucu komutları şifreli SSH ve GitHub API üzerinden güvenle yönlendirilir.
